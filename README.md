# Броня-Люкс — концепт редизайна главной

**Живое превью:** https://kjhccc.github.io/bronia-lux-redesign/

Это статичный прототип главной страницы: HTML + CSS + немного JS, без сборки и библиотек.
Нужен, чтобы согласовать направление, а не как готовая замена WordPress-сайту.

## Как посмотреть

- Онлайн: https://kjhccc.github.io/bronia-lux-redesign/
- Локально: откройте `index.html` двойным щелчком — сайт откроется в браузере без сервера.

- Всё работает локально; интернет нужен только для шрифтов Google Fonts.
- Мобильную версию смотрите в DevTools (F12 → Ctrl+Shift+M) или с телефона в той же сети,
  если поднять локальный сервер (например, `npx serve`).
- Форма демонстрационная: данные никуда не отправляются, показывается экран «Заявка принята».

## Что было на сайте (аудит от 25.10.2026)

Проверял главную и 10 внутренних страниц: замеры в headless Chrome, разбор HTML, заголовков,
метатегов, изображений и поведения на 1440 и 375 px.

| Что | Как было | Почему это мешает |
| --- | --- | --- |
| Заголовок страницы | «Броня-Люкс» на всех страницах | Нет города и услуг — сайт не находят по запросам «двери в СПб» |
| Description | Одна и та же на всех страницах, только про двери | Окна, потолки, кухни и ремонт в поиске не участвуют |
| H1 | Нет ни на одной странице | Поиск и скринридеры не понимают главную мысль страницы |
| Тексты услуг | 23–38 слов на страницу | Нечего ранжировать, клиенту нечего читать |
| Призыв к действию | На главной 16 кликабельных элементов — в основном меню и телефоны | Нет кнопки «Замер» / «Рассчитать» — заявку взять негде |
| Первый экран | Шапка 837 px на десктопе, почти весь экран на телефоне | До услуг и контактов нужно долго листать |
| Изображения | 6 картинок, ни у одной нет `alt` и размеров | Плохо для SEO, доступности и вёрстки |
| OG-теги | `og:image = path/to/image.jpg` | Репост в мессенджере выглядит пустым |
| Плейсхолдеры | «Раздел «Контакты»», «Modal title», ссылка «Перейти» с пустым `href` | Выглядит как недоделанный сайт |
| Технически | WordPress 6.2.14, PHP 5.6.40 (не поддерживается с 2018) | Риск безопасности и проблем с обновлениями |
| Вес страницы | 1,44 МБ, из них 1,18 МБ — CSS; 25 запросов | Много лишнего, особенно для мобильного интернета |
| Мобильный вид | `maximum-scale=1` в viewport | Запрещает масштабирование — минус к доступности |
| Контакты | Нет адреса, реквизитов и политики обработки данных | Нет доверия и формальной базы для форм по 152-ФЗ |

Скорость при этом нормальная: LCP около 0,6 с, сдвигов вёрстки нет. Проблема не в скорости,
а в структуре, текстах и отсутствии сценария заявки.

## Что в концепте

- **Один экран — один смысл.** Тёмный первый экран с широкой фотографией, крупным заголовком
  и двумя действиями: «Вызвать замерщика» и «Смотреть услуги».
- **Фирменный бордовый** взят из логотипа (`#8a005c`), добавлены тёплый бумажный фон, графит
  и латунный акцент. Заголовки — Prata, текст — Inter.
- **Услуги как система:** 6 направлений в сетке с иконками, номерами и короткими пояснениями.
  Наведение подсвечивает карточку бордовым.
- **Доказательства вместо обещаний:** бесплатный замер, цены заводов, оплата после установки,
  профессиональный монтаж; шаги работы; цифры (50+ моделей, 4 производителя, 9:00–23:00, 0 ₽ замер).
- **Заявка как главный сценарий:** форма с валидацией, маской телефона, согласием на обработку
  данных и экраном благодарности. Плюс мобильная панель «Позвонить / Бесплатный замер».
- **Контент, которого не было:** FAQ с ответами на возражения, блок «Каталог новосёла»,
  контакты с географией и ссылкой на карту, политика конфиденциальности (шаблон).
- **SEO-база:** уникальный title и description, один H1, OG-теги, JSON-LD
  `HomeAndConstructionBusiness`, alt у фотографий, `loading="lazy"` для галереи.
- **Доступность:** контраст текста не ниже 4,5:1, фокус-рамки, управление с клавиатуры,
  `prefers-reduced-motion`, нормальный viewport без запрета масштаба.
- **Без зависимостей:** только два файла стилей/скрипта и локальные изображения.

## Что заменить перед публикацией

1. **Форма.** Подключить обработчик: CRM, почта или Telegram-бот. Сейчас это демо-отправка.
2. **Реквизиты и адрес.** В подвале и политике стоят заглушки «ИНН / ОГРН — заполнить».
   Адрес шоурума на сайте не публиковался — его нужно добавить, если он есть.
3. **Политика.** Шаблон проверить у юриста и указать оператора, ИНН, адрес.
4. **Фотографии.** Сейчас использованы четыре снимка с действующего сайта (2019 год, баннерные
   пропорции). Для финальной версии нужна съёмка: фасад, входная дверь в интерьере, окно,
   потолок с подсветкой, кухня, процесс монтажа, портрет бригады.
5. **Ссылки.** В прототипе пункты услуг ведут на форму. В продакшене — отдельные страницы
   с текстами, ценами и галереями (это же нужно для SEO).

## Как перенести на WordPress

Два пути:

1. **Своя тема по этому макету.** Главная собирается из блоков ACF, услуги — отдельные
   страницы/каталог, форма — через плагин или свой обработчик. Дольше, но клиент управляет
   контентом сам.
2. **Статическая главная + WordPress для остального.** Макет заливается как есть, форма уходит
   в CRM. Быстро и дешево, но контент правится в коде.

В обоих случаях сначала стоит обновить PHP и WordPress: 5.6 и 6.2 — устаревшие версии.

## Ограничения прототипа

- Одна страница; внутренние страницы услуг не нарисованы.
- Нет каталога, цен и корзины — для дверей это чаще заявка/замер, а не онлайн-оплата.
- Отзывов нет намеренно: не выдумываю социальные доказательства. Их лучше подключить
  с Яндекс.Карт или ВКонтакте.
- Логотип используется исходный; при желании можно перерисовать в вектор.
